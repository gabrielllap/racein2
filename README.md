# Mini Car Racing Game

A simple 2-player racing game made with Python.  
Players control mini cars and compete to reach the finish line first.

## Features

- 2-player local gameplay
- Simple graphical interface
- Real-time car movement
- Finish line detection
- Lightweight and beginner-friendly project

## How to Play

Each player controls a car using the keyboard.

Example controls:

- **Player 1:** `W A S D`
- **Player 2:** `Arrow Keys`

The first player to cross the finish line wins the race.

## Requirements

- Python 3.x

Depending on your project, you may also need:

```bash
pip install pygame
```

## Run the Game

```bash
python main.py
```

Replace `main.py` with your actual game file if different.
